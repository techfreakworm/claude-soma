# Claude Soma

> A body for Claude. Hermes-Agent's value in 10% the code, by riding Claude Code's native rails.

Claude Soma (Greek *soma*: "body") wraps Claude Code with a Telegram channel, voice in/out, a project orchestrator that spawns persistent independent agent teams per workstream, and a showcase dashboard at [claude.mayankgupta.in](https://claude.mayankgupta.in). Runs on a single Oracle Cloud Ubuntu ARM VPS. Authed via Claude Max subscription only — no API keys.

See [docs/superpowers/specs/2026-05-22-hermes-claude-design.md](docs/superpowers/specs/2026-05-22-hermes-claude-design.md) for the design and [docs/superpowers/plans/2026-05-22-hermes-claude-v1.md](docs/superpowers/plans/2026-05-22-hermes-claude-v1.md) for the implementation plan.

Status: in development. (Project originally drafted as "Hermes-Claude"; renamed Claude Soma at first publication.)
